# BUG-002: No overheat alarm at exactly 35.0 C (REQ-07)

- Version: 1.1.0-rc1
- Severity: High (safety function)
- Found by: `tests/test_safety.py::test_overheat_threshold[35.0-ALARM]`

## Steps

1. Start the device.
2. Set the sensor temperature to 35.0 C.
3. Send `STATE?`.

## Expected

`STATE ALARM` and heater off. The alarm must trigger at temp >= 35.0 C.

## Actual

`STATE NORMAL`. The alarm only triggers above 35.0 C (35.1 C triggers it).

## Notes

Passes on 1.0.0. The heater can keep running at the overheat limit.
