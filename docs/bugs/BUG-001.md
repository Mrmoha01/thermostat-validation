# BUG-001: SET 30.0 rejected with ERR RANGE (REQ-03)

- Version: 1.1.0-rc1
- Severity: Medium
- Found by: `tests/test_setpoint.py::test_setpoint_at_limit_is_accepted[30.0]`

## Steps

1. Start the device.
2. Send `SET 30.0`.

## Expected

`OK`. 30.0 C is the upper limit of the allowed range and is inclusive.

## Actual

`ERR RANGE`. The upper limit is treated as exclusive. `SET 29.9` is still accepted.

## Notes

Passes on 1.0.0. Users cannot select the maximum setpoint.
