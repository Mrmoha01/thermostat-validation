# BUG-003: RESET clears alarm while temperature is still 30.0 C or higher (REQ-07)

- Version: 1.1.0-rc1
- Severity: High (safety function)
- Found by:
  - `tests/test_safety.py::test_reset_after_alarm[30.0-ERR HOT-ALARM]`
  - `tests/test_safety.py::test_reset_after_alarm[31.0-ERR HOT-ALARM]`

## Steps

1. Start the device.
2. Set the sensor temperature to 36.0 C. `STATE?` returns `STATE ALARM`.
3. Set the sensor temperature to 30.0 C.
4. Send `RESET`.

## Expected

`ERR HOT` and the state stays ALARM. Reset is only allowed below 30.0 C.

## Actual

`OK` and the state changes to NORMAL. Same result at 31.0 C. At 32.0 C the reset is
refused, so the limit in the firmware seems to be 32.0 C instead of 30.0 C.

## Notes

Passes on 1.0.0. The heater can be re-enabled while the device is still hot.
